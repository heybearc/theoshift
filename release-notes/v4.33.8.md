# What's New in Version 4.33.8

**Released:** October 26, 2026

---

## 🔧 Improvements

### Chat alerts name the event
On a phone, a new chat notification uses the event name as the title. The message preview still shows which conversation it came from.

Open the site once after this update so the phone picks up the new alert title.

### Station checkbox
On Positions, the checkbox for a station is on the left and no longer says **Station**. Check it to bulk edit, delete, or set the overseer and keyman for this day’s shifts. Open the station to select one shift.

---

## 💡 What You Need to Know

- No action is required, other than opening TheoShift on your phone once so chat alerts use the event name.
