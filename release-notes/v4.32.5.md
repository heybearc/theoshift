# What's New in Version 4.32.5

**Released:** October 8, 2026

---

## 🐛 Bug Fixes

### Imported volunteers show up on the list
A CSV import could report success while the new people stayed off the Volunteers page. They now appear on that event's roster as soon as the import finishes.

### Chat opens without stalling
Opening chat on a large event no longer rewrites a channel for every position on each visit. Pinned messages and the volunteer view of chat load with the rest of the page.

---

## 💡 What You Need to Know

- If an earlier import looked empty, those people are on the roster now. Refresh the Volunteers page and set the status filter to All.
- No action is required for chat.
