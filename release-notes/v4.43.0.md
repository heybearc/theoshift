# What's New in Version 4.43.0

**Released:** November 3, 2026

---

## ✨ New Features

### Choose the dates when you clone an event
The clone window asks for the new start and end dates. Shifts move with the start date when you include positions. You can change the end date if the new event is shorter or longer.

**How to use it:**
1. Open the event and choose **Edit Event**.
2. Choose **Clone Event**.
3. Set the new name, start date, and end date, then choose what to copy.
4. The end date has to be on or after the start date.

To move a copy later, change its start date and save. The shifts move by the same number of days.

---

## 🐛 Bug Fixes

### A failed clone keeps what you entered
If the copy cannot be created, the window stays open with the dates and options you already chose, and the message appears in that window.

### Phone contacts open the dialer
Overseer and keyman phone numbers in the phone app open the dialer even when the number is stored with parentheses or dashes.
