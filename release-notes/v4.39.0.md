# What's New in Version 4.39.0

**Released:** October 31, 2026

---

## ✨ New Features

- **One keyman or overseer's people** - On Volunteers, choose a keyman or overseer to see the volunteers assigned to him, with assignments, count times, and lanyards.
- **Check-in only with IVS** - Check-in appears on that list, and on the phone arrivals list, only when the event uses the IVS module.

## 🐛 Bug Fixes

- **Enter count shows your assignment** - While viewing the site as a volunteer, the count page shows that person's count assignment. The full station list stays on the staff count screen.
- **Assignment details open** - Tapping an assignment on the phone shows the shift, who else is on the position, and the overseer and keyman.
- **Who submitted a count** - Group counts show a name. A volunteer sign-in is recorded, and counts already saved show the group's primary counter when the original name was not stored.

## 📝 Notes

- While you are using view-as on a phone, the bottom bar is Dashboard and Events.
- Reload the page if you still see the previous count list or tab bar.
