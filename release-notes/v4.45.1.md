# What's New in Version 4.45.1

**Released:** November 8, 2026

---

## 🐛 Bug Fixes

### Oversight sign-in on the phone
Signing in as oversight on the phone no longer fails with "Request failed." Use the same email and password as the website.

---

## ✨ New Features

### Choose Oversight or Volunteer
The phone sign-in screen has a switch for Oversight and Volunteer. Pick one, then sign in. This arrives with the next app update.

---

## 💡 What You Need to Know

- Volunteer sign-in is unchanged: email link or a sign-in code.
- The Oversight / Volunteer switch is in the updated phone app. Until that update is installed, the current app still signs oversight in with the website password once this release is live.
