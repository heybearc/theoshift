# What's New in Version 4.34.0

**Released:** October 30, 2026

---

## ✨ New Features

### Acknowledge a pinned announcement
Organizers can post in the event Announcements chat and pin one message. That message appears on each volunteer's dashboard, on a phone and on a computer, until they tap **I've read this**. Pinning a different message asks them to read it again. Volunteers can read Announcements and cannot post there.

---

## 💡 What You Need to Know

- Open the event chat, choose **Announcements**, send the update, and pin it.
- The dashboard banner stays until that volunteer acknowledges it.
- No other action is required.
