# What's New in Version 4.36.0

**Released:** October 30, 2026

---

## ✨ Sign in on the phone app

Volunteers who have the TheoShift app on an iPhone or Android phone can sign in with the same email link they already use. The app shows assignments for the current event and event chat.

The website is unchanged. Opening the sign-in email in a browser still opens the volunteer dashboard.

---

## 💡 What You Need to Know

- The app is not in the App Store or Google Play yet. Use the website until someone gives you the app.
- If the app asks for a server address, use the same TheoShift site you already open in the browser.
- No action is required if you only use the website.
