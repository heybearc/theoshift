# What's New in Version 4.33.6

**Released:** October 26, 2026

---

## 🐛 Bug Fixes

### Bulk create opens on Positions
**Bulk create** on the Positions day board opens again. You can set the number range, name, area, and shift pattern, then create the stations.

**How to use it:**
1. Open an event and go to **Positions**.
2. Choose **Bulk create**.
3. Set the range and shift pattern, then create the stations.
