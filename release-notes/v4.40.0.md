# What's New in Version 4.40.0

**Released:** October 31, 2026

---

## ✨ New Features

### Open a station from the roster
On Volunteers, each assignment name opens that station on Positions, with the day, time, and area when those are set. If the person is a counter, that count is listed on the same row and opens the count session.

A keyman or overseer sees the people under their care the first time they open Volunteers.

### Station diagram
On Documents, an admin or overseer can choose one PDF or image of the stations. Assignments then include **Show on diagram**, which opens that picture with the station name so a volunteer can find the label.

Leave **No diagram** selected and nothing changes. The diagram is not added to the volunteer's document list.

**How to use it:**
1. Open the event and go to **Documents**.
2. Upload the station picture if it is not there yet.
3. Under **Station diagram**, choose that file and save.
4. Open a volunteer's assignment and choose **Show on diagram**.

---

## 💡 What You Need to Know

- Events without a diagram stay the same.
- Changing a shift still happens on Positions.
- Reload Volunteers if you do not see the new links yet.
