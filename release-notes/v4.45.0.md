# What's New in Version 4.45.0

**Released:** November 8, 2026

---

## ✨ New Features

### Open the rest of TheoShift from the phone
The Tools tab opens the website on the same phone, already signed in. Volunteers can reach IVS requests, help, and feedback. An oversight sign-in adds the event tools used on the website, such as positions, volunteers, counts, and lanyards.

**How to use it:**
1. Open the TheoShift app and sign in.
2. Tap **Tools**.
3. Choose the page you need. It opens in the app.

### Chat alerts on the lock screen
When a chat message arrives and the app is not open, the phone can show an alert. The app icon shows how many messages are waiting.

---

## 💡 What You Need to Know

- Allow notifications for TheoShift if you want lock-screen alerts.
- The app is still shared directly. It is not in the public App Store or Google Play yet.
- The website works the same way if you do not have the app.
