# What's New in Version 4.32.2

**Released:** September 15, 2026

---

## ✨ New Features

### Positions day board is now the default
Opening **Positions** on an event now uses the day-board layout (stations by day, per-shift overseers). Classic Positions is still available if you need it.

**How to use it:**
1. Open an event and choose **Positions**.
2. Use the day tabs to move between days.
3. Choose **Use classic layout** only if you want the older list/grid.

---

## 🔧 Improvements

### Volunteer sign-in is email-only
Volunteers sign in with a secure email link. PIN login, PIN admin pages, and PIN resets have been removed.

---

## 🐛 Bug Fixes

### Volunteer notes stay saved
Notes entered on a volunteer profile now show up again on the list and in edit, instead of going blank after save.

---

## 💡 What You Need to Know

- Existing events keep working. Positions still has the same assignments; only the default screen changed.
- Volunteers who used a PIN should use the email sign-in link on the login page.
- Classic Positions remains at the same URL if you bookmark it.

---
